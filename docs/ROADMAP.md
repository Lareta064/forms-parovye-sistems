## Что нужно для каждого калькулятора
1. **Формула** — `CALC['<код>']` в `calc-formulas.js` (для большинства — простая алгебра).
2. **Страница** — свёрстанный `calc-N.pug` с разметкой `data-*`. ← основной объём работ
   (52 новые страницы; нет в проекте). Рекомендуется **генерировать из шаблона**, т.к. входы/выходы/единицы
   известны из `formulas/tlv_app_reverse/calculators.json`.
3. **Ссылка** на странице-меню `calc-main.pug`.
4. **Калибровка** по toolbox.tlv.com (для большинства не требуется — формулы полные).

## Общие «строительные блоки» (сделать один раз, до фаз)
- **Свойства воды** ρ(T), μ(T) — для гидравлики воды (плотность можно брать из IF97 область 1; вязкость жидкой воды — отдельная корреляция, в IF97-модуле она сейчас не годится при высокой плотности).
- **Свойства воздуха/газа** — идеальный газ ρ=p·M/(R·T), вязкость воздуха.
- **Психрометрия влажного воздуха** — для 14500, 14600.
- **Генератор pug-страниц** из шаблона + автодобавление в меню.
- Доп. категории единиц: площадь, энергия, коэф. теплоотдачи/теплопроводности (для конверторов).

## Фаза 3 — Котёл, стоимость, рекуперация (15 шт.)
- **11410/11420/11430 + 11440/11450 + 11460/11461 (7)** — ✅ ГОТОВО (calc-36..42), сверено с TLV
  (КПД 75.179, Ce 0.99757, Cs 2415, сухость ΔT 6.908, смесь точно). hfw=region1(0.101325,Tfw).
  Сухость: ΔT=(h1−hg2)/cp(Ts2); смесь: ps=p·(1−a/100), выходы tempDrop в tempDiff.
- **12210–12230 Конденсатопроводы (4)** — ✅ ГОТОВО (calc-43..46). Vtemp=vf+Rfs·(vg−vf) после вскипания
  Cp→Rp; эфф. вязкость двухфазного = вязкость воды при Tsat(Rp). Сверено с TLV: выбор трубы совпадает,
  Δp +2%. 12210/12230 — упрощённые по скорости (жидкость).
- **12110/12120/12140 Рекуперация тепла конденсата (3)** — ✅ ГОТОВО (calc-48/47/49), сверено с TLV ТОЧНО.
  Экономика (helper `recoveryEcon`): Hr [Вт]; RecoverValue=3.6·Hr·h·Ce/1e6 (×1000 ₽/год); AnnFuelSave=3.6·Hr·h/(Hf·η/100);
  FuelConserv=Hr·0.86/(hs/4.186−Tfw)/mfw·100. Закрытая(12120): Hr=(Tc−Tfw)·mc/0.86. Открытая(12110): смешение
  Tm=(Tc·mc+(mfw−mc)·Tfw)/mfw, при Tm>Tдоп — обрезка до Tдоп, остаток в UnrecoverHeat. Выпар(12140): mfs=mc·(hf(Cp)−hf(Fp))/hfg(Fp),
  Hr=mfs·(hg(Fp)/4.186−Trw)/0.86. Слаги TLV: economic-analysis-{closed,open}-recovery.html, economic-analysis-flash-steam.html.
- **12130 Теплообменник** — ✅ ГОТОВО (calc-50), сверено с TLV ТОЧНО (включая крайние режимы). Модель:
  Tc=T1+mc·4.19·(Tsat(pc)−T1)/(SG·1000·Ql·c) — потолок смешения; T2=T1+(Tc−T1)·ηT/100; масса греющего
  пара ms=SG·1000·Ql·c·(T2−T1)/hfg(Ps); возвращённое тепло Hr=ms·(hg(Ps)−4.186·Trw)/3.6 [Вт]; далее recoveryEcon.
  ВАЖНО: энтальпия сырой воды у TLV линейна (4.186·Trw), не IF97 — это даёт ровно 0.000%.

## Фаза 4 — Сложная физика / калибровка (4 шт.)
Психрометрия (calc-formulas.js): ps по IF97 (Psat), P=101.325 кПа; X=0.622·ps/(P−ps)·1000 [г/кг];
V=0.287055·Tк/(P−ps) [м³/кг]; dewPoint() — обратная к ps бисекцией. Сверено с таблицей TLV humid-air-table:
в рабочем диапазоне (≤50°C) X/ps ±0.13%, V точно; выше 50°C у TLV своя заниженная корреляция V (квирк, не критично).
- **14600 Свойства влажного воздуха** — ✅ ГОТОВО (calc-51). Таблица: X, ps, V по температуре.
- **14500 Осушение сжатого воздуха** — ✅ ГОТОВО (calc-52). Формула TLV: mc=(X1−Xr)·Qa·60/Vtemp/1000,
  X1=Φ·X(Tam), Xr=X(Tc)·(760−p2)/(760·Pr−p2), Vtemp=V(Tam)·(760−p1)/(760−Φ·p1), Pr=Pабс/101.325,
  p1/p2=ps(Tam/Tc) в мм рт.ст. Сверено: точка росы и X1 точно, mc −0.55% (психром. шум таблицы TLV).
- **13500 Антиконденсатная изоляция** — ✅ ГОТОВО (calc-53), сверено с TLV ТОЧНО (3 точки 15/50/15 мм).
  Неявное (d1+2L)·ln((d1+2L)/d1)=2λ/α·(Ti−Tdp)/(Tdp−Tam); α неподвижного воздуха=7.4 (калибр.);
  λ из INS_LAMBDA при Tmean=(Ti+Tdp)/2; толщина округляется до 5 мм (бисекция по D). Слаг: water-piping-insulation-thickness.
- **11470 Эконом. толщина изоляции** — ✅ ГОТОВО (calc-54). КЛЮЧЕВОЕ ОТКРЫТИЕ: стоимость изоляции Ci2 на
  ВЫБОР толщины НЕ влияет (Ci2 — только для денежного вывода, не реализуемого здесь); драйвер чисто
  энергетический. Толщина = перебор стандартных шагов 5 мм по минимуму f(L)=area_изол(L)+drv·Qr_пог(L),
  drv=Ce·A(i,m)·h·ρ, A(i,m)=(1−(1+i)^−m)/i — аннуитет (i=0→A=m), ρ=6.75e-9. Теплопотери — модель calc-13
  (α=alphaSurface(v), λ итерацией). Сверено с TLV: 15/19 точек точно, остальные ±5мм (предел из-за шага 5мм);
  обобщается по Ce/i/m/v/Ps/размеру. Qr ±0.5% (DN150+ до ~10% из-за α). Авто-Ts=Tsat(Ps) совпадает точно.
  Слаг: steam-economical-insulation-piping.
