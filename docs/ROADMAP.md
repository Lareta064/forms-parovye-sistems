# План реализации оставшихся калькуляторов (52 из 69)

Готово 17 (паровая группа). Осталось 52. Фундамент (IAPWS-IF97, единицы, трубы, движок,
гидравлика, модель клапанов) уже построен и переиспользуется — поэтому остальное пойдёт быстрее.

## Что нужно для каждого калькулятора
1. **Формула** — `CALC['<код>']` в `calc-formulas.js` (для большинства — простая алгебра).
2. **Страница** — свёрстанный `calc-N.pug` с разметкой `data-*`. ← основной объём работ
   (52 новые страницы; нет в проекте). Рекомендуется **генерировать из шаблона**, т.к. входы/выходы/единицы
   известны из `formulas/tlv_app_reverse/calculators.json`.
3. **Ссылка** на странице-меню `calc-main.pug`.
4. **Калибровка** по toolbox.tlv.com (для большинства не требуется — формулы полные).

## Общие «строительные блоки» (сделать один раз, до фаз)
- **Свойства воды** ρ(T), μ(T) — для гидравлики воды (плотность можно брать из IF97 область 1; вязкость жидкой воды — отдельная корреляция, в IF97-модуле она сейчас не годится при высокой плотности).
- **Свойства воздуха/газа** — идеальный газ ρ=p·M/(R·T), вязкость воздуха.
- **Психрометрия влажного воздуха** — для 14500, 14600.
- **Генератор pug-страниц** из шаблона + автодобавление в меню.
- Доп. категории единиц: площадь, энергия, коэф. теплоотдачи/теплопроводности (для конверторов).

## Фаза 1 — «почти бесплатно» (16 шт., минимум физики)
Готовый движок/Units, формулы тривиальны. Быстрый набор объёма.
- **151xx Конверторы единиц (13)** — чистая конверсия. `Units` уже почти всё умеет; добавить площадь/энергию/теплофиз. коэффициенты. Можно сделать 1 универсальную страницу-конвертер вместо 13.
- **11350 / 11360 Stall point (2)** — `S=(Tb−(T1+T2)/2)/(Ts−(T1+T2)/2)·100`.
- **11130 Размер трубы по скорости, упрощ. (1)** — вариант готовой 11120.

## Фаза 2 — Вода и Воздух/Газ: гидравлика (18 шт.)
Переиспользуют движок труб и модель клапанов. Нужны свойства воды и воздуха (блоки выше).
- **Вода 13110–13150, 13200, 13300, 13400 (8)** — подбор/потери/скорость/расход + клапан/сопло.
  Клапан воды — несжимаемая формула: `Qw=0.0865·Cv·√(Δp/SG)` (с учётом FL/кавитации).
- **Воздух/газ 14110–14160, 14200, 14300, 14400 (10)** — то же для воздуха; клапан/сопло —
  уже готовая компрессионная модель (как для пара). 14140 — произвольный газ (мол. масса + вязкость как вход).

## Фаза 3 — Котёл, стоимость, рекуперация (15 шт.)
Новые формулы, но без сложной физики; энтальпии уже есть.
- **11410 КПД котла, 11420 стоимость энергии, 11430 стоимость пара (3)**
- **11440 / 11450 Сухость пара (2)** — баланс энтальпий.
- **11460 / 11461 Паровоздушная смесь (2)** — парциальное давление (Дальтон).
- **12210–12230 Конденсатопроводы (4)** — гидравлика конденсата (насыщ. вода + выпар).
- **12110–12140 Рекуперация тепла конденсата (4)** — экономика теплоутилизации.

## Фаза 4 — Сложная физика / калибровка (4 шт.)
- **11470 Эконом. толщина изоляции** — оптимизация (стоимость изоляции vs стоимость теплопотерь).
- **13500 Антиконденсатная изоляция** — расчёт толщины по точке росы.
- **14500 Осушение сжатого воздуха** — психрометрия (конденсат из сжатого воздуха).
- **14600 Свойства влажного воздуха** — психрометрическая таблица.
