# Инженерные калькуляторы — техническая документация

Справочник по реализации 17 калькуляторов паровых систем (аналог TLV Steam Toolbox).
Все расчёты выполняются **на чистом клиентском JavaScript, офлайн** — без сервера и интернета.

---

## 1. Что деплоить

На хостинг заливается **только содержимое папки `build/`** — это готовый статический сайт.

```
build/
├── *.html              страницы (калькуляторы calc-1…17, опросные листы index*, главная)
├── js/main.js          ВЕСЬ JavaScript, включая ВСЕ формулы всех калькуляторов
├── css/main.css        все стили
├── fonts/  img/        шрифты и картинки (в т.ч. картинки-формулы)
└── ui/                 UI-кит (визуальный референс, для прод-сайта не обязателен)
```

**НЕ заливается** (это инструменты разработки): `src/`, `formulas/`, `node_modules/`,
`gulpfile.mjs`, `package.json`, `tables/`.

Пересборка после правок: `npm run build` (разовая сборка) или `npm start` / `npx gulp`
(сборка + локальный сервер с авто-обновлением на http://localhost:3000).

## 2. Где находятся формулы

Отдельных файлов «по калькулятору» нет. При сборке Gulp **склеивает все `src/js/*.js`
в один файл `build/js/main.js`**. Поэтому на хостинге вся математика — в одном `main.js`.

Исходные модули (`src/js/`), которые попадают в `main.js`:

| Файл | Назначение | Глобальный объект |
|---|---|---|
| `calc-steam-if97.js` | Свойства воды и пара по стандарту **IAPWS-IF97** (области 1/2/4): температура/давление насыщения, энтальпия, удельный объём, скрытая теплота, теплоёмкость, вязкость | `window.SteamProps` |
| `calc-units.js` | Конверсия всех единиц измерения (давление abs/gauge, температура, расход, длина, энтальпия, уд. объём, вязкость, Cv/Kv и др.) | `window.Units` |
| `calc-pipes-data.js` | Таблица 165 типоразмеров труб (8 стандартов), наружный/внутренний диаметр | `window.PIPE_TABLE` |
| `calc-formulas.js` | **Все 17 расчётных функций** + гидравлика (трение, фитинги) | `window.CALC` |
| `calc-engine.js` | Связка HTML-формы с расчётом: чтение полей, конверсия в СИ, вызов формулы, вывод результата | — (работает на `DOMContentLoaded`) |
| `dropdown.js`, `hide-block.js`, `form-validate.js`, `acordion-menu.js` и др. | UI: выпадающие списки единиц, доп. опции, маска телефона, меню | — |

## 3. Как работает страница калькулятора

1. Страница `calc-N.html` подключает `css/main.css` и `js/main.js`.
2. `main.js` при загрузке создаёт глобальные объекты `SteamProps`, `Units`, `PIPE_TABLE`,
   `CALC` и инициализирует движок.
3. В HTML расставлены **data-атрибуты**, которые движок читает:
   - на форме: `data-calc="11110"` — код калькулятора;
   - на поле ввода: `data-var="stmPress" data-cat="pressureAbs"` — имя переменной и категория единиц;
   - на классе/размере трубы: `data-type="grade"` / `data-type="size"`;
   - на селекте (напр. изоляция): `data-type="select"`;
   - на поле результата: `data-out="pipeInDiam" data-cat="length"`.
4. Нажатие «Рассчитать» → движок собирает входы, конвертирует в СИ, вызывает `CALC['<код>']`,
   выводит результат в выбранных единицах.

Единица берётся из **текста кнопки** выпадающего списка (его поддерживает `dropdown.js`),
а не из `:checked` — это устойчиво к совпадению `name` у разных групп радио.

## 5. Краткое описание формул

Обозначения: `Ts` — темп. насыщения, `Tam` — окруж. среда, `ΔH` — скрытая теплота
(энтальпия пара − насыщ. воды), `V` — удельный объём пара, `ρ=1/V`, `d` — внутр. диаметр,
`v` — скорость, `Δp` — потери давления.

**Гидравлика паропроводов (11110/11120/11140/11150/11160)**
- Скорость: `v = ms/3600 · V / ((d/2)²·π)`
- Потери: `Δp = λ · L_экв · v² / (2·d·V)` (Дарси-Вейсбах)
- Коэф. трения `λ` — Колбрук-Уайт × 1.006, шероховатость ε по умолч. 0.05 мм
- Эквивалентная длина фитингов: `L_экв = L + Σ(n·K)·d/λ` (K-метод)
- 11110: перебор труб сортамента → наименьшая, где `Δp ≤ допустимых`
- 11120: наименьшая труба, где `v ≤ допустимой`

**Клапаны и сопла (11210/11220/11230)** — методика IEC 60534 (сжимаемый поток):
- докритический (`x < Fγ·xT`): `ms = 2.73·Cv·(1 − x/(3·Fγ·xT))·√(Δp·ρ)`
- запертый поток: `ms = ⅔·2.73·Cv·√(Fγ·xT·p1·ρ)`, где `x=(p1−p2)/p1`
- сопло: `Cv = C·(do/4.654)²`, `do` в мм

**Конденсат — нагрев (11330/11331/11340)**
- жидкость: `mc = c·SG·Q·(T2−T1)/ΔH·1000`
- воздух: `mc = (ca·γa)·Q·(T2−T1)/ΔH`
- периодич.: общее `= c·SG·V·(T2−T1)/ΔH·1000`, среднее `= общее / время`

**Конденсат — изоляция (11320) и прогрев (11310)**
- теплопотери: `Qr = 2π(Ts−Tam) / [ln(D/d1)/λ + 2/(D·α)]`, `D=d1+2L`, `d1`=наружный диаметр
- `mc = 3.6·Qr·L / ΔH`
- прогрев трубы: `mh = cp·Wp·L·(Ts−Tam)/ΔH` (нагрев металла) + лучистые потери за время прогрева

**Выпар (12310)**: `доля = (hf(p_конд) − hf(p_выпара))/hfg(p_выпара)·100%`, `m_выпар = доля·mc`

**Паровые таблицы (11510/11520/11530)** — напрямую из IAPWS-IF97.

## 7. Единицы измерения

`Units.toSI(значение, категория, символ)` и `Units.fromSI(...)`. Категории:
`pressureAbs` (→МПа абс, с учётом abs/gauge), `dPress` (→Па), `temp` (→К),
`massFlow` (→кг/ч), `mass` (→кг), `length` (→м), `velocity` (→м/с), `volume` (→м³),
`volFlow` (→м³/ч), `time` (→ч), `specHeat`, `enthalpy`, `specVol`, `dynVisc`, `cv`, `power`.

В таблице `units.json` из APK коэффициентов нет (только символы) — множители заданы вручную
в `calc-units.js`.

## 8. Как добавить/изменить калькулятор (рецепт)

1. **Формула** — добавить `CALC['<код>'] = function(inp){ … return {…}; }` в `src/js/calc-formulas.js`
   (вход и выход — в единицах СИ).
2. **Разметка** — на странице `calc-N.pug`: форме дать `data-calc="<код>"`, полям ввода
   `data-var`/`data-cat`, строкам результата `data-out`/`data-cat`.
3. **Единицы** — если нужна новая категория, добавить в `calc-units.js`.
4. `npm run build` → проверить на localhost → залить `build/`.

> Подводный камень вёрстки: в выпадающем списке единиц атрибут `checked` у радио должен
> совпадать с текстом кнопки — иначе движок прочитает не ту единицу (см. историю фикса в calc-11).
> И у разных списков единиц на одной странице должны быть **уникальные `name`** у радио.
