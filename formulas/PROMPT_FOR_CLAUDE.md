# Промт для старта работы

Скопируй и вставь в Claude Code при открытии этой папки.

---

```
Контекст задачи:

Клиент — Steamsys (steamsys.ru), компания по паровым системам. 
Запрос: собрать веб-калькуляторы для инженеров — аналог мобильного приложения TLV Steam Toolbox (com.tlv.tlvtoolbox).

Я разобрал это приложение и извлёк все данные. В этой папке лежит всё необходимое для разработки.

Прочитай AGENT.md — там полный контекст: структура данных, карта всех 69 калькуляторов, архитектурные решения, подводные камни.

Затем прочитай calculators.json — это главный файл: 69 калькуляторов с входами, выходами, формулами (SI и LaTeX) и описаниями переменных.

Задача: спроектировать и собрать веб-приложение с этими калькуляторами.

Начни с:
1. Прочитай AGENT.md полностью
2. Изучи структуру calculators.json (первые 3-5 записей)
3. Предложи архитектуру: стек, структуру компонентов, как обрабатывать два типа калькуляторов (формульные vs steam tables)
4. Задай уточняющие вопросы если нужно — до кода

Приоритеты клиента:
- Офлайн работа (все данные локальные, нет API-запросов)
- Русский интерфейс  
- Единицы: SI основные + возможность переключить на Imperial
- Мобайл-friendly
- Начать с паровых калькуляторов (группа 111xx + 115xx)

Ограничения:
- Steam tables (калькуляторы 11510, 11520, 11530) требуют IAPWS-IF97 — нужна JS-библиотека, не изобретать велосипед
- Трубные таблицы уже в pipes.json — не хардкодить
- Формулы брать из calculators.json, не переписывать вручную
```
