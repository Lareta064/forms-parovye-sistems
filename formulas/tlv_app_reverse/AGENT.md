# TLV Toolbox — Reverse Engineering Handoff

## Задача
Собрать веб-интерфейс с калькуляторами на основе данных из Android-приложения `com.tlv.tlvtoolbox` (TLV Steam Toolbox). Приложение — референс от клиента STEAMSYS: "хотим такие же офлайн-калькуляторы на вебе".

## Что здесь

| Файл | Описание |
|---|---|
| `calculators.json` | **Главный файл.** 69 калькуляторов: входы, выходы, формулы, LaTeX, описания переменных с единицами |
| `units.json` | 135 единиц измерения (SI + Imperial + MKS) с символами |
| `pipes.json` | 165 типоразмеров труб (JIS-SGP, ANSI, DIN и др.) — OD/ID/толщина в мм и дюймах |
| `UQS_CALCDOC.csv` | Исходник: формулы на 8 языках + LaTeX + описания переменных |
| `UQS_IOTABLE.csv` | Исходник: какие переменные используются в каждом калькуляторе (I/O матрица) |
| `UQS_PIPETABLE.csv` | Исходник: таблица труб |
| `UQS_UNIT.csv` | Исходник: единицы измерения |

| Код | Что считает |

> **⚠️ Важно:** Формулы для 115xx пустые — расчёт был в скомпилированном C++ (IAPWS-IF97 Standard).
> Нужна JS-реализация IAPWS-IF97. Варианты:
> - npm: `iapws` — чистый JS
> - npm: `freesteam` — WebAssembly порт C-библиотеки
> - Таблицы-интерполяции из открытых источников IAPWS

## Архитектура приложения (референс)

```
Android App
├── USteamCalc.java        — JNI-обёртка, вся логика в нативном коде
├── libusteamcalc.so       — C++ движок (591KB): IAPWS-IF97 + гидравлика
└── assets/usteamcalc/
    ├── UQS_CALCDOC.csv    — формулы и описания
    ├── UQS_IOTABLE.csv    — I/O матрица калькуляторов
    ├── UQS_PIPETABLE.csv  — трубные стандарты
    ├── UQS_UNIT.csv       — единицы измерения
    └── UQS_LABEL.csv      — UI-метки
```

Приложение полностью офлайн: нет сетевых вызовов, весь расчёт локально.

## Рекомендуемый стек для веб

```
Данные:        calculators.json + units.json + pipes.json (уже готово)
Steam tables:  npm install iapws  (или WebAssembly freesteam)
Формулы:       math.js или реализация вручную по LaTeX из calculators.json
UI:            React / Vue — форма инпутов → кнопка расчёт → вывод результатов
LaTeX рендер:  KaTeX (легче MathJax)
```

## Что НЕ нужно делать

- Писать свои трубные таблицы — они в `pipes.json`
- Искать формулы для клапанов Cv — они в `calculators.json`
- Переизобретать конвертацию единиц — структура в `units.json`
- Копировать `.so` бинарь — нельзя, нужна IAPWS-IF97 реализация
